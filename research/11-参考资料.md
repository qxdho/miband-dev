| 项 | 值 |

| 许可 | AGPL-3.0 |
| 规模 | 2646 文件 / ~17 MB |

| 官方文档 | https://abox.run/docs/usage/canopus |

文档站原文要点：

> Canopus 是专为 Xiaomi Vela 穿戴设备设计并开发的内核模块开发框架……通过 Lua 表盘，我们得以调用 NuttX Shell，并通过 `insmod` 命令载入编译好的内核模块……调用系统接口依赖于每个固件内的不同函数地址，因此同一个模块乃至管理器，都需要专门对每一台设备、每一个固件版本进行专门适配。

### 与本项目直接相关的符号

| 符号 | 地址（Thumb） | 原型 |
|---|---|---|
| `netdev_register` | `0xC1FC215` | `int(void *, int)` |
| `ipv4_input` | `0xC1F95C9` | `int(void *)` |
| `netdev_input` | `0xC1FC9F5` | `int(void *, void *, int)` |
| `register_driver` | `0xC1AFF61` | `int(const char *, const void *, uint32_t, void *)` |

⚠️ 这些网络符号标注的证据 ID 是 `EVID-NET-001`，但 `evidence/` 下**不存在这个文件**。相比之下蓝牙相关的 `EVID-BT-1043-*` 是齐全的。所以网络符号的出处比蓝牙符号弱，用之前应独立验址。
