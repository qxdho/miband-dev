# 表盘

<StatusBadge status="sourced" verified="2026-10-24" />

> 表盘是一份**资源包 + 一段 Lua 脚本**，打包成 `.bin` 后由系统加载渲染。它和快应用是两条独立的路：表盘不跑 AiotJS，也不能调快应用 API。

## 能做什么

- 替换表盘的布局、字体、指针、数据字段（时间、步数、心率等）；
- 做成完全自定义的界面，甚至用 Lua 画动态效果；
- 打包成系统认识的文件，通过官方/第三方工具安装。

## 前置条件

- 会一点 **Lua**（语法很小，半天够用）；
- 知道目标机型的**分辨率与圆角**（见[机型能力矩阵](/start/models)），否则做出来会错位；
- 一个打包/解包工具，例如 [Mi8WfBinTool](https://github.com/zhy8388608/Mi8WfBinTool)（第 8 代工具，是否兼容 9/10 需自行核实）。

## 与相邻板块的边界

- 想要**交互、网络、API** → 那是[快应用](/quickapp/)，不是表盘；
- 想换掉**整个系统的表盘加载逻辑** → 属于[固件](/firmware/)层，风险高得多。

## 注意

表盘的 `.bin` 格式**没有公开规范**，社区工具多为逆向所得。不同代数、不同固件版本之间可能不兼容 —— 这正是本站要求每页标注 `models` 与 `firmware` 的原因。
