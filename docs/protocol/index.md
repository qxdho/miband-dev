# BLE 协议

<StatusBadge status="unverified" verified="2026-10-24" />

> 手环和手机之间走的是 BLE：先是配对与认证，然后才是各种数据同步。这一层是**横向的** —— 快应用、表盘、固件、原生都会用到它。

## 这一层解决什么问题

- 第三方程序怎么**连上**手环（GATT 服务、特征值、MTU）；
- **认证**：小米的加密握手是怎么做的，凭证从哪来；
- **同步**：通知、健康数据、运动记录、表盘/应用安装包。

## 与相邻板块的边界

- 想**写个替代 App** → 属于本层，但不是本站重点（本站不做 Mi Fitness 替代品教程）；
- 想通过手机给手环**装快应用** → 目的在[快应用](/quickapp/)，协议只是手段；
- 想读**手环本地存储** → [固件](/firmware/)层。

## 注意

协议是逆向出来的，且**随固件版本变化**。任何一页都必须写清楚对应的固件版本区间；对不上就标 `unverified`，不要写「最新版通用」。
