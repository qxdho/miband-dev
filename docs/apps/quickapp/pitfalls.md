# 快应用常见问题

<StatusBadge status="sourced" verified="2026-10-24" />

以下条目按社区记录中出现的频率排序。每条给出判断方法与处理方式；无公开来源的条目标为待验证。

## 1. 设备搭载 Vela 但没有快应用引擎

红米手环 3 搭载 Vela，但没有快应用引擎，无法安装快应用。

**判断方法**：查看官方规格页是否写明支持快应用，或以同型号设备实测为准。「搭载 VelaOS」不代表支持快应用。

## 2. 分辨率写死导致换机型后布局错乱

手环 9 为 192×490，手环 10 为 212×520，手环 9 Pro 为 480×336。写死像素的布局在其他机型上会溢出或错位。

**处理方式**：使用相对单位，预留安全区，先在最小分辨率机型上调通。

## 3. 圆角与安全区裁切

圆角半径从 48px 到 999px（接近胶囊形）不等，贴边内容会被裁切。

**处理方式**：关键信息放在屏幕中央区域，仅装饰元素贴边。

## 4. 模拟器可运行，真机白屏

模拟器的分辨率、系统版本与权限模型可能与真机不同。模拟器通过只说明代码无语法错误。

**处理方式**：尽早使用真机验证，至少在目标机型之一上跑通后再视为完成。

## 5. manifest 未声明权限

使用 `@service.health`、传感器等能力时，若 `manifest.json` 未声明对应权限，真机上会静默失败或直接报错。

**处理方式**：按官方 API 文档的权限要求逐项核对 `manifest.json`。

## 6. 包体积超出限制

`.rpk` 有体积上限，体积较大的图片与字体内嵌后容易超出。

**处理方式**：压缩图片、按需加载、优先使用矢量资源，打包后检查产物大小。

## 7. 签名与证书配置

打包与安装对签名有要求。证书配置错误时通常表现为安装失败，而非明确的错误提示。

**处理方式**：先跑通官方模板的签名流程，再修改包名与证书。

## 8. AiotJS 不是浏览器环境

AiotJS 由 quickjs 衍生，语法接近 Vue，但不提供 DOM，也不保证全部 ES 新特性与浏览器 API 可用。

**处理方式**：只使用文档列出的组件与 API；`window`、`document`、`fetch` 默认视为不可用。

## 9. 生命周期与后台限制

手环资源有限，应用切到后台或息屏后的行为与手机不同，定时器与长任务容易被挂起。

**处理方式**：不依赖长时间后台运行，保存状态并在回到前台时恢复。

## 10. 固件升级后行为改变

固件更新可能改变 API、权限模型与安装方式，网络教程的有效性有时效。

**处理方式**：记录验证时的固件版本。本站每页的 `verified` 字段用于标注该日期。
